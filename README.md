# Student Attendance System

A simple Student Attendance Management System developed using Python, Tkinter, and SQLite.

## Features

- Admin Login
- Dashboard
- Add Student
- Student List
- Mark Attendance
- Present / Absent Status
- Save Attendance
- Attendance Report
- Logout
- SQLite Database

## Technologies Used

- Python
- Tkinter
- SQLite

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.


5. Login using the admin username and password.

## Project Purpose

This mini project helps manage student details and attendance records digitally. It demonstrates Python GUI development, database connectivity, and basic CRUD operations.
